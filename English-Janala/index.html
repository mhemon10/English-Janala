Frequently Asked Questions

What is the difference between var, let, and const?
Var: Declares the Variable in Global Scope.
let: Declares the variable in block scope.
const: Declares block scoped but the value cannot be changed after assigned.
What is the difference between map(), forEach(), and filter()?
Map:Transform data and return a new array
ForEach: Just loop through the array without returning anything
Filer:Filter elements that meet a condition
What are arrow functions and how they are different from regular functions?
It is an alternative of regular functions and it different by its declaration it is declared like (test)=>{}. Regular functions are declared with the function keyword.
How do JavaScript Promises work?
A Promise in JavaScript is an object that represents the eventual completion or failure of an asynchronous operation.
How does closures work in JavaScript?
A closure in JavaScript is when a function has access to variables from its outer (parent) function even after the parent function has finished executing.
